## Возможности

- Активные запросы, сессии и блокировки; завершение процессов (для администратора).
- Размеры баз, схем и таблиц, временные и TOAST-таблицы.
- VACUUM и ANALYZE в фоне; PDF-отчёт по подключению на русском или английском.
- Журнал аудита; роли «Администратор» и «Аналитик».

Подробная инструкция — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Первый вход

1. Откройте приложение в браузере (по умолчанию http://localhost:8000).
2. Войдите под учётной записью администратора. Логин и пароль задаются при первом запуске.
3. Добавьте подключение: в верхней панели нажмите **+**, заполните поля и нажмите **Подключиться**.

Подключения создаёт только администратор. Вкладки Greenplum появляются только для подключений Greenplum и Greengage.

## Безопасность

- Задайте `SECRET_KEY`, `DB_CONNECTION_ENCRYPTION_KEY` и `INITIAL_ADMIN_PASSWORD`. Значения по умолчанию небезопасны.
- Не открывайте приложение в интернет без HTTPS.
- Создайте отдельную учётную запись для каждого сотрудника.

## Частые вопросы

- **Ошибка 503 «Превышен лимит соединений».** Слишком много параллельных запросов к одной базе.
- **«Объект заблокирован другой транзакцией».** База занята другим процессом. Приложение сообщит причину через несколько секунд.
- **В PDF нет раздела «Ресурсоёмкие запросы».** На базе не установлено расширение `pg_stat_statements`.
